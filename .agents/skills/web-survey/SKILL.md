# 网站全站遍历 → 参考手册（/web-survey）

给定一个网页（主页），遍历该网站能收集到的所有页面信息，整理成一份**中文参考手册**。**浏览与记录以英文界面为主**（如管理页面切到 English 版进入；站点无英文支持则以当前语言为准），手册中文叙述、UI 文案保持原样——记录最主要语言版本，其他语言界面可对照英文原文直接翻译定位。通用方法论，不绑定任何特定项目/系统。

> 边界：`/research` = 多源搜索（关键词 → 多站点汇总）；`/web-survey` = 单站点全量只读遍历（给定一个 URL → 该站所有页面）。两者互补：先 research 找到站点，再 web-survey 深挖。

## 生产/对外系统交互授权（优先于通用步骤）

站点属生产/对外系统时，交互操作需先获得用户明确允许：

1. **交互需先确认**：开始遍历前先向用户说明需交互遍历并**征得明确允许**；未授权时仅可用 `browser_snapshot` 只读查看当前页
2. **登录**：先征得用户允许再填凭据；密码、key、token 只输入不记录（对应铁律 4）
3. **只读叠加**：铁律的「提交/保存/创建/删除类按钮一律不点」在任何情况下生效

## 触发与意图

| 用户输入 | 行为 |
|---------|------|
| `/web-survey` 无参数 | 先 Grep 当前项目内已有 URL 记录，找到直接导航；找不到问用户要主页 URL（不猜路径/端口） |
| `/web-survey <URL>` | 遍历该站点并生成手册 |
| "把所有菜单都走一遍" / "生成参考手册" / "探测一下这个网站" | 同上 |

## 铁律（违反即失败）

1. **只读遍历**：导航、展开、查看详情 OK；**Create / Edit / Remove / Delete / 保存 / 提交 / Enable / Disable** 类按钮**一律不点**
1b. **层层递进**：主页/当前页上的可点击链接（含外链按钮）必须**点开查看**，形成 主页 → 子页 → 子页 的递进链，不能只停在一个页面就下"无子页/已遍历完"结论
1c. **遍历边界（防无限套娃，按用户口径固化）**：
   - **基础站点**（用户指定 / 项目已记录的站点 URL）：**同域内层级遍历到底**——递归跟进所有子路由，不设深度上限（如 `docs.example.com/xxx/` → 同一 `docs.example.com` 域内所有子页都进）
   - 遍历中打开的**外域网站**（域名 ≠ 基础站点域）：**只浏览首层所有页面**——到该外域站点后，浏览其入口页及直接可达的首层页面（深度 1）后即停止，**不向下递归**（不点进其子页/文章详情）
   - 例外：用户另行指定某外域站点也完整遍历时，按指定范围执行。此边界写死，防止无休止探索
1d. **大规模条目采样规则**（条目数超百（如插件市场/话题页数千仓库）时）：**按受欢迎程度从高到低**（优先 stars，无 stars 的考虑 downloads/forks 等计数）向下挖掘；**上限约 100 个**，或设**下限阈值**（如 <X stars 不做深挖）——两者取其一即可；产出物中明示「按什么排序、挖了多少、阈值多少」，未覆盖的条目不逐个分析
2. **遇到提交类/写入类按钮**：记下该功能的字段布局 → 退出该功能 → 继续下一个（粗略覆盖即可，不逐按钮深挖）
3. **界面英文为主**：操作/浏览时用**英文界面**（站点支持语言切换则切 English 后进入；无英文支持则以当前语言为准）；**手册正文用中文**，UI 文案（页面标题/字段/菜单/按钮名）**原样**记录——记录主语言版本，其他语言界面可用英文对照翻译定位
4. **凭据不落盘**：登录密码、key、token 只输入不记录；存档中一律占位符
5. **每步落 UI log**：URL + 快照要点 + 操作，写 `raw-logs/ui-YYYY-MM-DD.md`（`[Playwright]` 前缀，目录按所在项目惯例）
6. **打开页面先搜记录**：先 Grep 站点所在项目已有的 URL/raw-log（`raw-logs/`、`ops-log.md`、`research/`、`docs/` 等），找到直接导航；禁止猜路径/端口
7. 遍历失败（跳转异常/大量 ERR）如实记下继续，不中断全程

## 步骤

### 0. 准备

- 确认主页 URL（Grep 项目内记录 → 无则问用户）
- 识别访问障碍并处理：
  - **自签证书**：优先用浏览器自动化通道放行（如 CDP `Security.setIgnoreCertificateErrors {ignore:true}` 于当前页面上下文放行后重新导航）；若当前环境不支持该通道，如实汇报用户，由用户侧处理（浏览器放行/换访问方式），**不自行绕过**
  - **登录**：先征得用户允许再填凭据（密码不落盘）；用户已登录则直接用现有会话
  - **代理/MTU 类网络问题**：如实汇报，移交用户侧，不深挖
- 生产/对外系统站点按上文「生产/对外系统交互授权」先确认交互授权

### ① 主页结构抓取（关键：先拿到 URL 全集）

- 打开主页后，抓「导航/侧边栏」完整结构：
  - 展开所有菜单（顶层 → 子项），收集**全部链接 href**，建立 `菜单层级 ↔ URL` 映射
  - 兜底：抓取页面内所有 `<a href>` 去重，标注所属菜单
- 这一步决定遍历范围——**不要漏子菜单**

### ② 逐页只读遍历

对 URL 全集逐页：
1. 导航进入，等页面渲染（SPA 需等待数据加载）
2. 抓取：页面标题（breadcrumb）+ 正文核心（表格/列表/卡片/表单字段）
3. **表单类页面**：打开 Create/Edit 表单 → 记录字段名+placeholder（原样）→ **Cancel/Esc 关闭，不提交**
4. 每页结果记入 UI log 一行：`URL | 标题 | 要点`

### ③ UI log 落盘

- `raw-logs/ui-YYYY-MM-DD.md`：全程 URL + 快照要点 + 操作顺序 + 观察（无害报错也记），段落 `[Playwright]` 前缀
- 主日志（如 `ops-log.md` 或当日 raw log）留指针行：`→ 全文已迁至 ui-YYYY-MM-DD.md`

### ④ 生成参考手册 `docs/survey/<site>-survey-ref.md`

> 统一输出到 `docs/survey/`（不存在则创建），与 `deploy/`、`usage/` 等手册目录区分。

```
# <站点名> 参考手册（<版本/环境口径>）

> 生成：<YYYY-MM-DD 探测日期>（全站只读遍历，零配置改动；英文界面记录，无英文支持则以当前语言）
> 地址：<主页 URL>

## 0. 访问与登录
| 项 | 值 |（URL / 证书 / 登录 / 语言口径（English）/ 平台 API）

## 1. 菜单全景地图（<N> 组 / <M> 页）
| 顶级菜单（EN） | 子页（EN） | URL | 实测内容（中文叙述，UI 原样） |

## 2. 关键实测快照
（中文叙述；核心数量/状态/可操作对象，名称保留原文）

## 3. 操作路径（典型流程，如建卷/建用户步骤）
（每个功能：入口（菜单路径原样）→ 表单字段（原样）→ 提交按钮名（原样）→ 中文附注）

## 4. 只读探测红线
（哪些按钮不点；可安全操作哪些）

## 5. 观察项 / 待办
```

- **手册正文用中文**；页面标题、菜单、字段、按钮名一律保持**原样**（主语言记录，其他语言界面可对照原文定位）
- 独立自包含：不引用其他文档

### ⑤ 收尾

- 更新站点所在项目的操作日志（如 `ops-log.md`）：探测范围、产出文件、红线执行情况
- `git status --short`：有未入库 → 提示 `/checkpoint`

## 产出物

| 文件 | 内容 |
|------|------|
| `docs/survey/<site>-survey-ref.md` | 全站参考手册（交付物） |
| `raw-logs/ui-YYYY-MM-DD.md` | 探测全程 UI 日志（证据） |
| 操作日志更新 | 探测记录 + 产出指针 |
