# agents-md-lang-rule — AGENTS.md 语言铁律注入

## 用途与定位

- **前置条件**：目标项目的指令真源已是 `AGENTS.md`（即已完成 [agents-md-migrate](../agents-md-migrate/) 迁移）。若只有 `CLAUDE.md` / 无 `AGENTS.md`，脚本会明确报错并提示先迁移，**不做任何改写**。
- **作用**：把一段固定内容——「中文母语输出」最高优先级规则块——注入指定项目 `AGENTS.md` 的最显眼位置（H1 标题之后，通常即文件最前面）。
- **幂等**：目标文件已含「语言铁律」→ 直接跳过，零改动；可反复执行。
- **定位**：显式接受**目标项目路径**的运维工具，可在技能库或任意位置运行、一次一个项目；与 agents-md-migrate 的「副本自管」作用域模型无关。

## 注入内容（全文）

> ## ⚠️ 语言铁律（最高优先级，适用于每一次会话、每一个回合，无例外）
>
> 你是一位**中文母语**的 AI 工程助手。你的一切输出——包括：
> - **内部思考链（reasoning / Thought 块）**
> - 工具调用前的分析、调用后的总结
> - 最终回复
>
> 都必须使用**简体中文**。英文仅允许出现在：技术名词、命令、JSON 键、代码、文件名、模型/服务名等**原样引用**中。
>
> **正例**（合规）：思考链为「先检查数据库连接配置，再确认超时参数」，回复为中文说明。
> **反例**（违规）：思考链出现整段英文，如 "I need to check the connection timeout…"。
>
> **判定标准**：若思考链或回复中出现连续多个英文单词组成的句子（非代码/技术名词/命令），即视为违反本铁律，必须改为中文重新生成。

> ⚠️ 逐字节**内容真源内嵌在 `inject.py` 的 `BLOCK` 常量**。本文件仅作展示（供人工审阅）；如需修改注入内容，请改脚本，并同步本节展示。

## 执行方式（铁律：一切操作走脚本）

本 skill 目录内的 **`inject.py` 是唯一执行入口**。agent 读取本文件后，必须用 shell 工具执行该脚本；**禁止**用自然语言手工编辑目标文件、禁止绕过断言手改、禁止在脚本失败后「人肉修复」——只报告并停下：

```bash
PY="<本 skill 目录>/inject.py"     # 库内：ai-agent/claudecode/skills/agents-md-lang-rule/inject.py

python3 "$PY" <目标项目根目录> --dry-run   # ① 预览：插入点 / 字节变化（不改文件）
python3 "$PY" <目标项目根目录>             # ② 正式注入
```

- **目标项目根目录必填**（可相对 / 绝对 / 含 `~`）；先 `--dry-run` 后正式执行。
- 脚本输出即执行证据；退出码：`0` 成功 / 已存在跳过，`1` 失败，`2` 用法错误。

## 行为规则

| 场景 | 行为 |
|------|------|
| `AGENTS.md` 不存在 | ❌ 报错退出，提示先运行 agents-md-migrate |
| `AGENTS.md` 为符号链接 | ⚠️ 拒绝处理，人工介入 |
| 已含「语言铁律」 | ⏭️ 跳过，零改动（幂等） |
| 首行是 H1（`# …`） | 插入 H1（及其后空行）之后，块前后各留一个空行 |
| 无 H1 | 置于文件最前，块后留一个空行 |
| 行尾风格 | 跟随原文：CRLF 文件注入 CRLF 块；LF 文件注入 LF 块 |
| 块外原文 | 逐字节零改动（含末尾无换行等原始形态） |

## 断言链（脚本自动，失败即回滚）

```
前置：目标目录存在 / AGENTS.md 为普通文件（符号链接、缺文件均拒绝）
① 切片重组：head + rest ≡ 原文件字节
② 字节等式：新文件字节数 = 原文件字节数 + 插入字节数（严格等式）
③ 剥离还原：新内容去掉插入块（首次出现处）后 ≡ 原文件；「语言铁律」查重保证无歧义
④ 备份：写入前备份原文件并校验 md5；写入走「同目录临时文件 → 读取校验 → os.replace 原子替换」
⑤ 终检：替换后再读回校验 md5；任何失败 → 自动从备份回滚原文件（不得手工补修）
```

## 已知边界

- **只动一个文件**：仅写入 `<目标项目>/AGENTS.md`；不碰 `CLAUDE.md`，不创建其他文件（临时文件用后即删）
- **非 UTF-8 内容**：按字节透传（surrogateescape），查重与块按 UTF-8 语义处理
- **运行环境**：Python 3.8+，纯标准库零依赖；Linux / macOS / Windows 通用
- **不做的事**：不给多个项目批量注入；不删除已注入内容；不合并/改写块外任何文字
- Windows 上命令用 `python3`（或 `py`），路径加引号

## 设计说明

- **为什么接受显式目标路径**：本 skill 的用途就是「给指定项目注入」——作为技能库的运维工具使用，一次一个项目；不复刻 agents-md-migrate 的副本作用域模型。
- **为什么强制先有 AGENTS.md**：AGENTS.md 是跨工具事实标准（opencode V2 只读 AGENTS.md）；向尚以 CLAUDE.md 为真源的项目注入会产生指令漂移，故引导先迁移。
- **为什么幂等查重词是「语言铁律」**：该词是规则块独有标志，既不误伤用户的「中文输出要求」等自定义表述，也能防止重复注入。
- **为什么块内容内嵌脚本**：字节级注入要的是确定性——内容真源随脚本走，md5/字节断言才能闭环；比自然语言临场生成可靠。
- **与 agents-md-migrate 的关系**：迁移（CLAUDE.md → AGENTS.md）先行，注入（语言铁律）随后；两者均为纯脚本 + 断言 + 回滚设计。
